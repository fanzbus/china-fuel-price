开发者 API

免 Key · CORS 全开 · 数据来源 qiyoujiage.com（仅取价格数字与调价时间）· 预测仅供参考，以发改委为准。

Base URL 为当前域名。示例：

curl https://china-fuel-price.fansys.workers.dev/api/prices?province=上海
curl https://china-fuel-price.fansys.workers.dev/api/prices?fuel=95
curl https://china-fuel-price.fansys.workers.dev/api/history
curl https://china-fuel-price.fansys.workers.dev/api/trend?province=上海&fuel=95
curl https://china-fuel-price.fansys.workers.dev/api/meta
curl https://china-fuel-price.fansys.workers.dev/api/forecast
curl https://china-fuel-price.fansys.workers.dev/api/export.csv
OpenAPI YAML 下载 CSV RSS /health

Webhook：订阅调价变更可轮询 /api/meta 的 fetched_at，或订阅 /rss.xml。暂不提供推送服务。

接口一览

  • GET /api/prices[?province=&fuel=] — 全部 / 按省 / 按油号
  • GET /api/history — 历史快照
  • GET /api/trend?province=&fuel= — 单省单油号走势
  • GET /api/meta — 更新时间、下次调整、数据质量
  • GET /api/forecast — 国际油价预测（含各省预测价）
  • GET /api/global — 全球对比（待接入）
  • GET /api/cities — 城市级（收集中）
  • GET /api/export.csv — CSV 导出
数据来源：qiyoujiage.com · 仅供参考，以国家发改委官方通知为准 状态GitHub
